Atomic Structure

Atomic Structure

Key concepts

  • Atomic number is the proton count. Isotopes have the same atomic number but different neutron counts.
  • An orbital is described by quantum numbers; each orbital holds at most two electrons with opposite spins.
  • For a subshell with angular momentum quantum number l, there are 2l + 1 orbitals. The s, p and d subshells contain 1, 3 and 5 orbitals respectively.

Worked connection

A p subshell contains three orbitals, allowing at most six electrons. Carbon-12 and carbon-14 both contain six protons.

Watch out

An orbital is not a classical circular path. A subshell contains orbitals, while a shell can contain multiple subshells.

Concept walkthrough and worked checkpoints

Use these seven checkpoints to connect the core ideas, practise applications and identify assumptions. Try each before opening its solution.

1. An s orbital has a commonly represented probability-density shape that is:

Spherically symmetric

s orbitals have spherical angular symmetry; an orbital is a quantum description, not a classical path.

2. For principal quantum number n = 3, allowed l values are:

0, 1, 2

l ranges from 0 through n − 1.

3. A single orbital can hold at most:

Two electrons with opposite spins

The Pauli principle permits two electrons per orbital with opposite spin projections.

4. Hund’s rule favours filling degenerate orbitals first with:

Singly occupied parallel spins

The ground-state arrangement maximises unpaired parallel-spin occupancy before pairing in degenerate orbitals.

5. For a p subshell, possible ml values are:

−1, 0, +1

For l = 1, magnetic quantum number runs from −l to +l.

6. An electron’s de Broglie wavelength relates to momentum as:

h/p

Matter-wave wavelength is inversely proportional to momentum.

7. Heisenberg uncertainty concerns simultaneous precision of position and:

Momentum

The uncertainties satisfy ΔxΔpx ≥ ħ/2, a quantum limitation rather than only instrument imperfection.

Practice questions and explanations

Try each question before opening its answer.

1. The maximum number of electrons in a p subshell is:

  1. 2
  2. 6
  3. 10
  4. 14
Show answer and explanation

Answer: B. 6

Three p orbitals can each contain two electrons.

2. Isotopes have the same number of:

  1. Neutrons
  2. Protons
  3. Nucleons
  4. Always electrons and neutrons
Show answer and explanation

Answer: B. Protons

Atomic number, and therefore proton count, remains the same.

3. For a d subshell, the value of l is:

  1. 0
  2. 1
  3. 2
  4. 3
Show answer and explanation

Answer: C. 2

The subshell labels s, p, d, f correspond to l = 0, 1, 2, 3.

4. An s orbital has a commonly represented probability-density shape that is:

  1. Spherically symmetric
  2. Always a two-lobed dumbbell
  3. Always four-lobed
  4. A circular electron track
Show answer and explanation

Answer: A. Spherically symmetric

s orbitals have spherical angular symmetry; an orbital is a quantum description, not a classical path.

5. For principal quantum number n = 3, allowed l values are:

  1. 0, 1, 2
  2. 1, 2, 3
  3. Only 3
  4. 0, 1, 2, 3
Show answer and explanation

Answer: A. 0, 1, 2

l ranges from 0 through n − 1.

6. A single orbital can hold at most:

  1. Two electrons with opposite spins
  2. Four electrons
  3. Six electrons
  4. Two electrons with identical four quantum numbers
Show answer and explanation

Answer: A. Two electrons with opposite spins

The Pauli principle permits two electrons per orbital with opposite spin projections.

7. Hund’s rule favours filling degenerate orbitals first with:

  1. Singly occupied parallel spins
  2. Electron pairs in one orbital only
  3. No electrons
  4. Opposite spins in the same orbital before all others
Show answer and explanation

Answer: A. Singly occupied parallel spins

The ground-state arrangement maximises unpaired parallel-spin occupancy before pairing in degenerate orbitals.

8. For a p subshell, possible ml values are:

  1. −1, 0, +1
  2. Only 0
  3. 0, 1, 2
  4. −2, −1, 0, +1, +2
Show answer and explanation

Answer: A. −1, 0, +1

For l = 1, magnetic quantum number runs from −l to +l.

9. An electron’s de Broglie wavelength relates to momentum as:

  1. h/p
  2. hp
  3. p/h
  4. h + p
Show answer and explanation

Answer: A. h/p

Matter-wave wavelength is inversely proportional to momentum.

10. Heisenberg uncertainty concerns simultaneous precision of position and:

  1. Momentum
  2. Mass number
  3. Element symbol
  4. Charge sign
Show answer and explanation

Answer: A. Momentum

The uncertainties satisfy ΔxΔpx ≥ ħ/2, a quantum limitation rather than only instrument imperfection.

11. For principal quantum number n=2, the maximum total electron capacity of a shell is:

  1. 8 electrons
  2. 4 electrons
  3. 12 electrons
  4. 16 electrons
Show answer and explanation

Answer: A. 8 electrons

A shell has n² orbitals and two electrons per orbital: capacity=2n². Answer: 8 electrons.

12. For a subshell with angular quantum number l=1, the number of orbitals is:

  1. 1.5
  2. 4.5
  3. 6
  4. 3
Show answer and explanation

Answer: D. 3

Allowed m_l values run from −l to +l, giving 2l+1 orbitals. Answer: 3.

13. A one-electron ion has Z=2 and n=2. Bohr energy magnitude is:

  1. 20.4 eV
  2. 27.2 eV
  3. 13.6 eV
  4. 6.8 eV
Show answer and explanation

Answer: C. 13.6 eV

Hydrogen-like energy is −13.6 Z²/n² eV; report its magnitude. Answer: 13.6 eV.
