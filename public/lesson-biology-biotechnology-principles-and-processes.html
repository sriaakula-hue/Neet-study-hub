Biotechnology: Principles and Processes

Biotechnology: Principles and Processes

Key concepts

  • Recombinant DNA technology joins DNA segments using enzymes and introduces them into a suitable host.
  • Restriction endonucleases recognise specific DNA sequences. DNA ligase joins DNA fragments. Vectors carry inserted DNA.
  • PCR amplifies a selected DNA sequence using primers, nucleotides and a thermostable DNA polymerase through repeated temperature cycles.

Connect the ideas

A plasmid vector can carry an inserted gene into bacteria. An origin of replication and selectable marker help maintain and identify the vector.

Common mistake

PCR amplifies DNA; it is not a method for directly multiplying proteins.

Practice questions and explanations

Try each question before opening its answer.

1. The enzyme used to join DNA fragments is:

  1. DNA ligase
  2. Pepsin
  3. Amylase
  4. Lipase
Show answer and explanation

Answer: A. DNA ligase

Ligase seals breaks in the sugar–phosphate backbone.

2. PCR directly amplifies:

  1. DNA
  2. Proteins
  3. Lipids
  4. Whole organs
Show answer and explanation

Answer: A. DNA

PCR creates many copies of a targeted DNA region.

3. A selectable marker helps identify:

  1. Cells carrying the vector
  2. Only cell size
  3. Only pollen maturity
  4. Protein flavour
Show answer and explanation

Answer: A. Cells carrying the vector

Marker expression allows identification or selection of transformed cells.

4. Restriction enzymes recognise specific:

  1. DNA sequences
  2. Only cell colours
  3. Only amino-acid flavours
  4. Only sugar concentrations
Show answer and explanation

Answer: A. DNA sequences

Restriction endonucleases cut at or near defined recognition sequences, with enzyme-specific patterns.

5. Sticky DNA ends contain:

  1. Single-stranded overhangs
  2. Only intact full cells
  3. Only proteins
  4. Only circular RNA
Show answer and explanation

Answer: A. Single-stranded overhangs

Complementary overhangs can base-pair, helping compatible fragments join before ligase seals the backbone.

6. The origin of replication in a vector supports:

  1. Replication in a suitable host
  2. Only fluorescence
  3. Only protein digestion
  4. Only spore formation
Show answer and explanation

Answer: A. Replication in a suitable host

A functional origin permits the vector DNA to be replicated using host-compatible machinery.

7. PCR requires primers because DNA polymerase needs an existing:

  1. 3′ hydroxyl end
  2. Protein nucleus
  3. Lipid droplet
  4. Carbon dioxide molecule
Show answer and explanation

Answer: A. 3′ hydroxyl end

The enzyme extends an annealed primer rather than initiating a strand from nothing.

8. In PCR, denaturation separates DNA strands by:

  1. Heating
  2. Only freezing
  3. Only protein digestion
  4. Only light reflection
Show answer and explanation

Answer: A. Heating

Heating disrupts duplex base pairing; later cooling permits primer annealing.

9. A thermostable polymerase is useful in PCR because it tolerates:

  1. Repeated high-temperature steps
  2. Only high gravity
  3. Complete absence of nucleotides
  4. No template
Show answer and explanation

Answer: A. Repeated high-temperature steps

It remains functional through repeated denaturation cycles better than heat-sensitive enzymes.

10. Gel electrophoresis separates DNA fragments partly by:

  1. Size during movement in an electric field
  2. Only odour
  3. Only carbon isotope
  4. Only sequence name
Show answer and explanation

Answer: A. Size during movement in an electric field

Negatively charged DNA migrates through a gel; smaller fragments generally move farther under comparable conditions.

11. Recombinant DNA technology joins genetic material from:

  1. Only nuclear neutrons
  2. Different suitable sources
  3. Only identical water molecules
  4. Only lipid tails
Show answer and explanation

Answer: B. Different suitable sources

DNA sequences can be combined for a planned function.

12. Restriction endonucleases cut DNA at:

  1. Specific recognition sites
  2. Every random amino acid
  3. Only membrane pores
  4. Only ribosomes
Show answer and explanation

Answer: A. Specific recognition sites

Sequence recognition underlies controlled DNA cleavage.

13. A palindromic DNA recognition sequence has matching reading patterns when each strand is read:

  1. Both only 3′→5′ with unrelated bases
  2. Without orientation
  3. As protein sequence
  4. In the same 5′→3′ direction
Show answer and explanation

Answer: D. In the same 5′→3′ direction

Complementary strands show the characteristic directional symmetry.

14. Sticky ends contain short single-stranded:

  1. Cell-wall spikes
  2. Lipid tubes
  3. Overhangs
  4. Protein tails
Show answer and explanation

Answer: C. Overhangs

Complementary overhangs can facilitate fragment pairing.

15. DNA ligase helps create recombinant molecules by sealing:

  1. Only lipids
  2. Phosphodiester backbone breaks
  3. Only hydrogen bonds between proteins
  4. Only nuclear envelopes
Show answer and explanation

Answer: B. Phosphodiester backbone breaks

Covalent joining completes compatible DNA connections.

16. A cloning vector requires an origin of:

  1. Replication
  2. Only translation
  3. Only nitrogen fixation
  4. Only photosynthesis
Show answer and explanation

Answer: A. Replication

The inserted DNA must be copied in the host system.

17. A selectable marker helps identify cells that:

  1. Always lack all DNA
  2. Contain no ribosomes
  3. Are necessarily dead
  4. Carry the vector or desired selection trait
Show answer and explanation

Answer: D. Carry the vector or desired selection trait

Selection distinguishes relevant transformants under chosen conditions.

18. A plasmid is commonly a small:

  1. Lipid droplet
  2. Cellulose fibre
  3. Extrachromosomal DNA molecule
  4. Protein coat
Show answer and explanation

Answer: C. Extrachromosomal DNA molecule

Many bacterial plasmids replicate separately from the chromosome.

19. Transformation in this context introduces foreign DNA into a:

  1. Blood vessel as the definition
  2. Host cell
  3. Pure atom
  4. Neutron beam
Show answer and explanation

Answer: B. Host cell

The recipient cell acquires the genetic material.

20. Bacterial competency refers to an ability to:

  1. Take up suitable DNA
  2. Only form spores
  3. Only digest cellulose
  4. Only produce methane
Show answer and explanation

Answer: A. Take up suitable DNA

Preparation can increase uptake during transformation procedures.

21. PCR stands for:

  1. Protein chromosome repair
  2. Plasma cell reproduction
  3. Primary carbon respiration
  4. Polymerase chain reaction
Show answer and explanation

Answer: D. Polymerase chain reaction

The method amplifies selected DNA sequences.

22. PCR denaturation separates the:

  1. Only chromosomes from tissues without lysis
  2. Only lipid layers
  3. DNA strands
  4. Only amino acids
Show answer and explanation

Answer: C. DNA strands

Heating breaks strand-pairing interactions.

23. PCR annealing allows:

  1. Cells to fertilise
  2. Primers to bind templates
  3. DNA to lose all bases
  4. Proteins to become DNA
Show answer and explanation

Answer: B. Primers to bind templates

Complementary primer binding sets the amplification endpoints.

24. PCR extension uses a polymerase to synthesise:

  1. DNA
  2. Only proteins
  3. Only lipids
  4. Only cellulose
Show answer and explanation

Answer: A. DNA

New nucleotides extend the primed DNA strand.

25. A thermostable polymerase is useful because it tolerates repeated:

  1. Only freezing without heat
  2. Only light pulses
  3. Only alkaline hydrolysis
  4. High-temperature cycles
Show answer and explanation

Answer: D. High-temperature cycles

Thermal resilience supports repeated PCR denaturation steps.

26. Gel electrophoresis separates DNA fragments mainly by:

  1. Only organism colour
  2. Only blood group
  3. Size under specified gel conditions
  4. Only amino-acid sequence
Show answer and explanation

Answer: C. Size under specified gel conditions

Smaller fragments generally move more readily through the matrix.

27. DNA moves towards the positive electrode because its backbone is:

  1. Metallic
  2. Negatively charged
  3. Positively charged
  4. Always neutral
Show answer and explanation

Answer: B. Negatively charged

Phosphate groups confer negative charge.

28. The DNA band corresponding to a shorter fragment generally migrates:

  1. Farther under comparable conditions
  2. Less far in every gel
  3. Nowhere
  4. Towards the negative electrode
Show answer and explanation

Answer: A. Farther under comparable conditions

Smaller DNA traverses gel pores more readily.

29. A bioreactor provides controlled conditions for:

  1. Only fossil dating
  2. Only clinical imaging
  3. Only rainfall collection
  4. Biological production
Show answer and explanation

Answer: D. Biological production

Culture performance depends on regulated physical and chemical parameters.

30. Downstream processing includes product recovery and:

  1. Only DNA denaturation
  2. Only light absorption
  3. Purification
  4. Only inoculation
Show answer and explanation

Answer: C. Purification

Production is followed by separation and preparation of the usable product.
